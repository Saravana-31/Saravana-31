## About

I'm Saravana P, a B.Tech Artificial Intelligence and Machine Learning student at **Kongu Engineering College**, graduating in 2027 and based in Tamil Nadu, India.

I build applications across the stack: from AI/ML workflows and API services to databases and user-facing interfaces. I'm especially interested in software that combines useful product design with practical AI, rather than adding a model where ordinary code would do the job.

- **AI applications:** LLM integrations, structured extraction, and recommendation workflows
- **Backend engineering:** Python, FastAPI, Flask, Node.js, and Express
- **Full-stack development:** React, Next.js, TypeScript, and database-backed applications
- **Applied ML:** CNN image classification and classical machine-learning workflows
